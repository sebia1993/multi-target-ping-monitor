# IP별·전체 IP HTML5 / PDF 보고서 (0.3.0)

## 사용 방법

일반 실행 화면 상단의 **보고서 저장**을 누릅니다. 저장할 IP를 체크하고 HTML5 또는 PDF를 선택합니다. 기본값은 현재 목록의 모든 IP입니다. 각 IP 행의 **저장 → 이 IP HTML5 / PDF 보고서**를 사용하면 그 IP만 선택된 상태로 저장 창을 엽니다. 여러 IP만 골라 하나의 보고서로 저장할 수도 있습니다.

대상 선택과 시간 선택은 별개입니다. **현재 그래프 구간**은 저장 창을 연 순간의 시간 범위를 사용합니다. **측정 전체**는 세션 시작부터 저장 시점까지 읽습니다. **직접 지정**은 시작·종료 시각을 지정합니다. 일시중지 IP는 목록에 포함하고, 이미 삭제한 IP는 현재 목록의 전체 저장에서 제외합니다.

각 행의 **현재 행 PNG 캡처**는 현재 화면 모양을 그대로 저장하는 별도 기능입니다. HTML5/PDF는 화면을 잘라 붙이는 것이 아니라 선택한 데이터로 그래프와 통계를 다시 그립니다. 따라서 화면 아래로 스크롤해야 보이는 IP도 빠지지 않습니다.

## 파일 구성

- HTML5: 스타일과 SVG 그래프가 들어 있는 단일 `.html`. 외부 스크립트·CDN·이미지 폴더·서버가 필요하지 않습니다. 전체 요약표에서 IP 상세로 이동할 수 있습니다.
- PDF: 전체 요약표, IP별 독립 페이지, 집계·해석 기준. 기존 QtGui의 QPdfWriter를 사용하며 QtPdf, 브라우저 엔진, 유료 API나 프린터 드라이버를 새로 요구하지 않습니다.
- 공통: 선택 IP와 별칭, 생성 시각·집계 구간·실제 표본 시각, 송신/수신/실패, 손실률, 최소/평균/최대 지연, 저장 시 상태·설정 주기, 응답 실패 표시.
- 실패 상세는 HTML에 최근 최대 20개, PDF 상세 페이지에는 최근 최대 3개 표본을 표시합니다. 전체 실패 수는 요약 통계에 포함합니다.

## 정확성과 한계

기존 CSV는 시각을 초 단위, 지연시간을 소수점 3자리로 저장합니다. 디스크와 실시간 데이터를 합칠 때 이 저장 표현을 기준으로 다중집합 차감하여 중복 집계를 막고, 실제로 같은 표현을 가진 여러 행은 보존합니다. 진행 중인 같은 초의 샘플이 보고서에 뒤늦게 섞이지 않도록 저장 요청 시각 직전의 완료된 초까지만 포함합니다. 현재 화면과 마지막 1초가 다를 수 있습니다.

통계는 선택 구간의 모든 유효 표본으로 계산합니다. 그래프만 IP당 최대 900개 시간 구간으로 집약하고 각 구간의 평균·최소·최대와 실패/중지 표시를 보존합니다. 빈 구간을 정상 응답선으로 연결하지 않습니다. IP를 선택할 때 다른 IP의 표본·실패 상세가 섞이지 않습니다.

PAUSED와 NO_PING_TARGET 표본은 손실률의 분모·분자에서 제외합니다. ERROR는 관측 실패에 포함하되 측정 오류 수를 따로 표시합니다. 따라서 손실률만으로 실제 네트워크 패킷 손실이나 장애 원인을 확정하면 안 됩니다. 표본이 없는 IP는 '표본 없음'으로 남기고 손실률을 0%로 위장하지 않습니다.

전체 이력은 세션 로그에서 스트리밍으로 읽고 실시간 tail과 합칩니다. 원본 파일 누락·손상 시에는 성공한 완전한 보고서로 표시하지 않습니다. 로그 경로 자체가 없는 경우에는 메모리 표본만 포함한다는 경고를 보고서에 표시합니다. 과거 로그에는 시간대 오프셋이 없으므로 UTC 시각을 추정하지 않습니다.

측정 엔진·스케줄러·세션 로그 형식은 변경하지 않습니다. 파일 집계·출력은 별도 QThread에서 처리합니다. 보고서용 QWidget 캡처를 worker에서 수행하지 않습니다. 저장 실패/취소 시 임시 파일만 정리하고 기존 파일은 보존하는 atomic writer를 사용합니다.

## 개발 검증

`python -m pytest tests/test_monitoring_reports.py -q`는 선택 IP, 시간 범위, 정밀도 차이에 따른 중복, 중지/빈 대상, 50대 120,000개 표본 스트리밍, HTML 이스케이프, PDF 페이지, 취소 중 기존 파일 보존, 일반 UI 접근, 실제 export thread를 검증합니다.

`python -m app.report_smoke <출력폴더>` 또는 패키지의 `MultiPingCheck.exe --report-smoke-test <출력폴더>`는 문서용 IP 50개의 합성 자료로 단일/전체 HTML·PDF와 UI PNG·검증 JSON을 생성합니다. 실제 Ping을 보내지 않으며 사용자 세션 경로를 임시 디렉터리로 격리합니다. 실제 운영망의 EDR·권한·NIC 환경 검증은 별도입니다.

CI에는 소스뿐 아니라 패키징된 EXE 안에서 HTML/PDF를 생성하는 검증도 포함합니다. 일반 자동 CI의 패키지 보관 정책은 유지하며, 이번 명시적 기능 요청 브랜치의 미리보기 자료만 1일 보관합니다.
