# IP별·전체 HTML5/PDF 보고서 저장

## 추가한 기능

- 각 IP 행의 **저장** 메뉴에서 해당 IP 화면 PNG 캡처 또는 HTML5/PDF 보고서 저장
- 상단 **전체 / 선택 IP 보고서 저장**에서 한 IP, 선택한 여러 IP 또는 현재 등록된 IP 전체 저장
- 현재 그래프 구간 / 측정 전체 / 직접 지정 시간 범위 선택
- 그래프·스타일이 내장된 단일 오프라인 HTML5와 전체 요약·IP별 상세 다중 페이지 PDF
- 스크롤 밖의 대상도 누락 없이 포함, 별도 저장 thread와 취소·오류 시 기존 파일 보존
- 선택 구간의 전용 IP 측정 표본으로 통계 집계, 일시중지·미측정 제외, 표본 없음 표시
- 전체 경로 측정의 최종 hop 복사본이 IP 송수신·실패 수에 중복 집계되지 않도록 수정

## 실행 및 저장 방법

1. 기존 프로그램을 종료하고 **MultiPingCheck_v0.3.0.zip**을 새 폴더에 전체 압축 해제합니다.
2. **MultiPingCheck.exe**를 실행합니다. Python 설치는 필요 없으며 **_internal** 폴더를 유지해야 합니다.
3. IP 입력 후 측정을 시작합니다. 해당 IP의 **저장** 또는 상단 **전체 / 선택 IP 보고서 저장**에서 대상·시간 범위·형식을 선택합니다.

기존 세션 로그는 삭제하지 않습니다. 보고서는 저장 시점의 기록이며 이후 측정으로 갱신되지 않습니다.
전체 원시 표본·이벤트 전체 이력 내보내기나 자동 원인 확정은 이번 기능의 범위가 아닙니다.
보고서에는 IP와 별칭 등 운영 정보가 들어가므로 외부 공유 전에 확인하세요. 자동 업로드·외부 변환 API는 사용하지 않습니다.

## 배포 검증 범위

기존 측정 worker·세션 기록 로직은 변경하지 않았습니다. 전체 자동 테스트, Windows 패키지 검증,
50-target release smoke 및 **실제 릴리즈 ZIP을 풀어 EXE에서 단일·전체 IP HTML/PDF를 생성하는 검사**를 통과해야 게시됩니다.

실제 운영망, 사용자 PC의 EDR·VPN 조합과 8·24시간 장시간 운용은 이번 자동 합성 검증과 별개입니다.
기존 v0.2.0 릴리즈는 유지합니다.
