# IP별 / 전체 모니터링 보고서 저장

새 보고서 기능은 `app.main`의 `ReportMainWindow` 진입점에서 제공됩니다.
기존 Ping worker와 기본 그래프 구현은 변경하지 않았습니다.

## 사용

- 상단 **전체 / 선택 IP 보고서 저장**: 현재 등록된 대상 목록에서 저장할 IP를 체크합니다.
- 각 IP 행의 **저장**: 해당 IP를 미리 선택한 보고서 창 또는 해당 행 PNG 캡처를 엽니다.
- 구간은 **현재 그래프 구간 / 측정 전체 / 직접 지정**, 형식은 **HTML5 / PDF**입니다.
- 전체 IP는 스크롤 위치와 무관합니다. 일시중지·표본 없음 대상도 빠뜨리지 않습니다.
- HTML은 PNG 그래프와 CSS를 포함한 단일 오프라인 파일입니다. PDF는 전체 요약과 IP별 상세 페이지를 포함합니다.
- IP·별칭·운영 정보가 포함되므로 외부 공유 전 내용을 검토하세요. 자동 업로드는 없습니다.

## 숫자와 시간의 의미

통계는 그래프 축소 표본이 아니라 선택 구간의 전체 유효 관측으로 계산합니다.
평균·최소·최대 지연은 성공했고 유효한 지연값이 있는 표본만 사용합니다.
손실률 분모에는 실제 측정 표본만 포함하며 `PAUSED`와 `NO_PING_TARGET`은 제외합니다.
표본 없음은 `-`로 표시하며 정상·손실 0%로 위장하지 않습니다.

기존 CSV의 시간(초)·지연(소수점 셋째 자리) 정밀도로 live/CSV를 맞춰 중복을 제거합니다.
저장 버튼을 누른 뒤 경로 선택을 완료한 시점에 범위·대상·별칭·live tail을 고정합니다.
측정 중 현재 미완료 1초는 고정한 live tail만 포함하여 이후 flush의 신규 표본이 섞이지 않게 합니다.
시각은 측정 PC의 로컬 시각이며 저장 시점에는 UTC 오프셋도 표시합니다.

그래프는 최대 800개 시간 칸으로 요약하고 평균 및 최소~최대를 그립니다.
빨간 칸은 그 시간 칸에서 실패 표본이 있었다는 의미이며 정확한 연속 장애 시간을 뜻하지 않습니다.
화면 상태·측정 주기는 저장 시점 값으로, 과거 구간의 상태·설정 이력을 뜻하지 않습니다.
자동 원인 판정, 전체 원시 표본 내장, 사용자 정의 이벤트 전체 내보내기는 이 기능의 범위가 아닙니다.

## 안정성 경계

집계·이미지 생성·HTML/PDF 작성은 별도 export thread에서 실행하며 측정 worker를 중지하지 않습니다.
PNG 화면 캡처만 GUI thread에서 해당 IP 행을 캡처합니다.
취소 또는 작성 오류 시 임시 파일을 제거하고 기존 파일을 보존합니다.
세션 로그가 없다고 자동으로 정상 보고서를 만들지 않습니다. 경로가 주어졌는데 로그가 없거나 손상되면 저장을 실패 처리합니다.
로그 경로 자체가 없는 경우 메모리에 남은 데이터만 사용했음을 보고서에 명시합니다.
전체 세션 원본 행을 메모리에 모두 적재하지 않으며 그래프 버킷과 bounded live tail만 유지합니다.

## 검증

`python -m pytest tests/test_monitoring_report_data.py tests/test_monitoring_report_export.py -q`

`python -m app.main --report-smoke-dir artifacts/report-export`

Windows 패키지에서도 `MultiPingCheck.exe --report-smoke-dir <출력폴더>`로 동일한 합성 HTML/PDF/PNG를 생성할 수 있습니다.
이 모드는 사용자 데이터 폴더를 격리하고 실제 네트워크 probe를 보내지 않습니다.
실제 운영망 ICMP와 Windows 수동 조작 검증은 자동 합성 테스트와 별개입니다.
